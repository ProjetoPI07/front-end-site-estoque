# AGENTS.md — front-sistema-estoque

Vite + React (JavaScript/JSX) + ESLint flat config. No test runner is configured.

Commands: `npm install`, `npm run dev`, `npm run lint`, `npm run build`, `npm run preview`. `lint` and `build` both pass on the scaffold.

## Backend this frontend talks to

- Target `../estoque-api/backend`: it contains the stock controllers **and** the auth controller. `../login-api/backend` is an older duplicate of the same `Funcionario` auth code (identical controllers/security config) — only use it if explicitly asked.
- Both APIs default to port **8080** (no `server.port` in `application.properties`). To run both, override one: `./mvnw spring-boot:run -Dspring-boot.run.arguments=--server.port=8081`.
- Both set CORS allowed origin to `http://localhost:5173`, which matches Vite's default dev port — don't change the port without updating backend CORS. CORS uses `allowCredentials(true)`: cross-origin `fetch` must send `credentials: 'include'` or an `Authorization: Bearer` header. `127.0.0.1` will be blocked.

## Auth and payload contract (from source, not docs)

- `POST /funcionarios/login` is public; returns `{userId, nome, email, token}` and also sets httpOnly cookie `authToken` (`SameSite=Strict`, 3600 s). The JWT filter accepts the cookie **or** `Authorization: Bearer <token>`. `POST /funcionarios/logout` clears the cookie. Everything except login/logout, Swagger and H2 console requires a valid token.
- `GET/POST /pecas`, `PUT/DELETE /pecas/{id}`: fields are `nome`, `valor`, `descricao`, `categoria`, `limiteEstoque`, `itemAtivo`; `id` is an Integer generated by the backend.
- **Ignore `../estoque-api/README.md` for API details.** It documents an obsolete model (`preco`, `data`, `tipo`, UUID ids, Live Server `:5500`) that does not match the current controllers/DTOs. Trust the controllers and DTOs.
- `POST /estoques` expects `{idPeca, quantidade}`. `POST /movimentacoes-estoque` expects `{pecaId, tipo: "ENTRADA"|"SAIDA" (case-insensitive), quantidade}`.
- Swagger UI at `/swagger-ui.html` and OpenAPI JSON at `/v3/api-docs` (springdoc 3.1.0) are the authoritative endpoint reference.
- H2 is in-memory (`jdbc:h2:mem:teste`) with `ddl-auto=create-drop` and `data.sql` seed data; all records reset on every API restart.
